# 🎤 Shasa Karaoke

Il karaoke professionale, finalmente moderno. Per chi le serate le fa davvero.

## ⬇️ Download
**[Scarica l'ultima versione](https://github.com/ShasaKaraokeOfficial/shasa-karaoke/releases/latest)** — prova gratuita con 5 utilizzi.

## ✨ Funzioni
- 🎶 Testo sincronizzato, parola per parola
- 🎚️ Cambio tonalità al volo, senza fermare la musica
- 🖥️ Testo sul secondo schermo / proiettore
- 📲 Prenotazioni dal telefono con QR, dritte nella scaletta
- 🎨 Temi istantanei per tutta l'app
- 🔄 Aggiornamenti automatici

## 💻 Requisiti
Windows 10/11 (64-bit) · 4 GB di RAM
